ABOUT THIS SYSTEM

The Disaster Response Incident Triage Dashboard is an explainable decision-support tool built for emergency response command centers. It aggregates disparate field reports and prioritizes them transparently to assist incident commanders in optimizing resource allocation.

EXPLAINABLE RULE-BASED SCORING ENGINE

Prioritization is computed via deterministic, auditable rules (+50 immediate danger, +30 trapped/injured, +20 structural/hazard, +10 population density) — not opaque machine learning or black-box algorithms. Every assigned score displays its exact mathematical rationale.

CRITICAL SAFETY DISCLAIMER

⚠️ Decision-Support Only: This application does not replace official emergency services (911/112/999) or human incident command authority. All field reports require ground truth verification by qualified dispatchers before emergency personnel deployment.
