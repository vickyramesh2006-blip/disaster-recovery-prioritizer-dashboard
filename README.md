Disaster Recovery Prioritizer Dashboard

Project Description

The Disaster Recovery Prioritizer Dashboard helps emergency responders manage disaster reports and identify people who need urgent help.

Key Features

•⁠  ⁠Report disaster incidents.
•⁠  ⁠Automatically prioritize emergency cases based on urgency.
•⁠  ⁠Display a priority list for rescuers.
•⁠  ⁠Track and manage reported incidents.
•⁠  ⁠Help rescuers make faster decisions

Objective

To support faster, organized, and more effective rescue operations during disasters.
